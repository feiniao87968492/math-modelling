# Modeling Memory — 规则记忆模板

每个阶段开始前读取此文件，将其中规则作为本阶段额外质量门控。阶段结束后沉淀新规则。

## 1. 通用反幻觉规则

- 不得凭空添加数据字段或约束
- 不得在未检查数据范围前解释趋势
- 不得把未验证的创新点写成论文主要贡献
- 所有结论必须指向结果文件、图表、统计检验或事实来源

## 2. 审题规则

- 审题阶段必须列出"确定事实"和"不确定信息"
- 对每个子问题必须说明输入、输出、评价标准
- 如果题目目标含糊，必须给出可执行解释并标记为 assumption

## 3. 数据处理规则

- 任何缺失值处理必须记录方法和数量
- 异常值不能直接删除，必须说明标准和影响
- 单位转换必须记录转换公式
- 时间序列数据禁止随机划分训练集

## 4. 建模规则

- 每个变量必须有单位、含义、取值范围
- 每个约束必须说明来源：题目明确、数据推导、合理假设、模型需要
- baseline model 必须足够简单且可复现

## 5. 结果解释规则

- 结果解释不得超过数据支持范围
- 排名类结果必须检查权重敏感性
- 预测类结果必须避免随机划分造成时间泄露
- 优化类结果必须检查可行性和活跃约束

## 6. 论文写作规则

- "显著""明显优于""鲁棒"等词必须有指标支撑
- 创新点必须有对比实验或消融实验
- 图注必须包含变量、单位、参数条件

## 7. 经验沉淀区（持续追加）

> 每次踩坑后在此追加规则：

```
### [日期] [规则标题]
- 触发条件：
- 规则内容：
- 反例/教训：
```
